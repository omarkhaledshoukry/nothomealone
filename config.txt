# Place beside the game HTML. Save as UTF-8 and reload the page after editing.
# Full-line comments start with # or ;. Sections and key names are case-sensitive.
# Use key = value. Quote text/paths/colors; arrays use JSON ["file-a.png", "file-b.png"].
# Probabilities: 0.25 = 25%; milliseconds: 120000 = 2 minutes. Booleans: true / false.
# Omitted/invalid values use built-in defaults; unknown keys are ignored with a console warning.
# Missing/unreadable/empty/HTML/malformed/duplicate-key files use all built-in defaults.
# Invalid min/max pairs use the default pair; all-zero level chances use default level chances.
# Settings load once, before level selection. No config file is required to play.
# Runtime values (camera position, collected letters, remaining time) are managed by the game.
# Direct local opening: choose the game folder. Use Change local files after editing these settings.
